# Blog Companion Repository

This repository accompanies the blog post **“Accelerate Local AI Inference with speculative decoding on Jozu RIC”** a Jupyter notebook (`main.ipynb`) with comands and examples demonstrated in the article.

The goal of this repo is **reproducibility**: if you follow both the blog and notebook, you will be able to install the required tooling, pull the quantized models from huggingface, package them as a ModelKit using KitOps, upload to Jozu Hub and run the model with Jozu Rapid Inference Container (RICs).
